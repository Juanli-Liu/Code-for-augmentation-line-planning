# 候选级 assumptions 直接提核

本版本实现直接提核、独立子集复核和加割。没有删除式缩核、证明追踪或第二层动车组交路验证。
固定完整集合割基线 `baselines/full_set_20261114_final` 保留不变；新的运行记录不冒充旧基线结果。

## 启用与复现

正式入口仍由 `main.cpp` 的 `kInputDataDirectory` 指定输入目录，默认是 `Test_data_complex`。
三份工作区算例的 `parameters.csv` 均已列出以下三项。修改当前算例参数表中的已有值即可切换模式，
无需运行根目录脚本或重新编译；下面是启用直接核的配置（不要追加重复参数）：

```csv
timetable_solver,2,backend,第一层使用CaDiCaL SAT
conflict_cut_mode,2,mode,1为完整集合割；2为assumptions直接核
core_verification_time_limit_seconds,60,second,直接核独立重建与复核预算
```

模式1允许MILP或SAT；模式2只允许SAT。两个新增参数省略时分别取1和60，保留历史CSV的行为。
复核预算可为0，此时原问题UNSAT后回退完整集合割；其他预算规则与原入口相同。
工作区三份参数表当前均设为后端1、割模式1、复核预算60秒，其他原始业务数据未改动。
固定基线快照中的原CSV保留不变。综合测试在副本上验证模式2的CSV配置和正式 `RunPlanningIteration(data)` 入口。

下列脚本仅用于开发验收和保存对照结果，不控制正式程序启用哪种模式。在项目根目录运行 PowerShell 7：

```powershell
& .\scripts\run_baseline.ps1 -OutputDirectory '.\baselines\assumptions_direct_20261114_final'
```

输出目录必须不存在；重复运行请换新目录。脚本查找MSBuild、构建正式程序和综合C++测试，运行真实
COPT/CaDiCaL，并保存源码/输入快照、哈希、环境、日志和逐轮报告。全部通过才生成 `PASS.txt`。
也可直接运行已编译的 `tmp\timetable_sat_tests_bin\Release\timetable_sat_tests.exe <项目根目录>`。
测试源码通过 `tests/timetable_sat_tests.vcxproj` 编译，使用MSVC 14.51.36231、COPT 8.0.7和CaDiCaL 3.0.1。

## 编码和候选映射

每次仅编码本轮选中候选和全部既有车；每个候选a分配一个正文字p_a，完整求解前对全部p_a调用
`assume()`。这些候选都必须开行，时刻表层不能自行撤销。新增文字不以单位子句永久固定。

`TimetableTrain::candidate_index` 给出车次归属；事件通过 `visit_index` 找到访问，再经
`train_index` 找到列车。`UseParticipants` 为每段业务约束收集所有参与候选、去重；`AddClause`
将参与候选文字的否定作为统一前缀。时间边界和单调性、活动、轨道唯一分配、同轨占用、安全间隔、
区间禁越行均按该规则编码。原来的次序/轨道activation条件保留，候选条件与其合取。

| 业务关系 | 候选前缀 |
|---|---|
| 既有背景 | 无 |
| 候选a自身、a内部多车、a与既有车 | ¬p_a |
| 不同候选a、b之间的关系 | ¬p_a ∨ ¬p_b |

候选停用后，其所有相关约束均不再限制背景或其他候选，私有变量可自由赋值。开启所有候选后，
这些前缀均为假，恢复完整业务约束。完整集合模式不分配候选文字，保留原有SAT编码。

逐轮报告输出候选→文字→全部车次映射及受其控制的子句数；跨候选子句在每个参与者下各计一次。
同一报告的时刻表数据提供事件、活动、访问和冲突关联。总子句统计不把这些重复计数相加。

## 提核与复核

原始求解返回20后，只对本次正候选assumptions调用 `failed()`，记录候选核K。返回10时解码并
独立检查见证；返回0时不提核、不加割。核可能等于完整集合，也不保证极小。

外层校验K是本轮C的无重复子集，用 `BuildTimetableData` 重新生成“K内全部车次＋全部既有车”，
使用原始时间域和完整约束，创建普通SAT实例复核（关闭assumptions）。不继承原CNF、临时固定值
或解。即使K=C也复核一次，不在复核后利用新核二次缩减。

只有复核UNSAT才能加 `sum(x_a,a∈K) <= |K|-1`。无核、非法映射、复核SAT/UNKNOWN/异常时，
回退原始已证UNSAT的C并记录原因。空核单独重建既有背景；背景UNSAT则终止，不添加空集合割。
原问题未定或异常没有不可行依据，不能使用此回退规则。

## 预算与报告

SAT单次预算包含编码、搜索及直接核查询；提核超预算时保留原始UNSAT但不使用部分查询结果。
复核预算包含数据重建及普通SAT调用，并裁剪到全流程剩余预算。编码和搜索预算检查为协作式，
解码、检查、文件写入、析构及一次API调用不能硬实时抢占。

生产逐轮报告保存完整选中集合、原始判定、候选映射、直接核、复核判定、实际割、回退原因，
以及主问题、SAT编码/搜索、提核、复核和本轮耗时。总耗时包括初始化、数据构建、逐轮报告、
复核和求解，计到最终汇总写入之前。

综合测试的输出：

- `cut_comparison.csv`：完整集合与直接核模式的轮数、割数、割规模、目标和各阶段总耗时。
- `cut_rounds.csv`：各轮集合、判定、直接核、实际割和耗时。
- `assumptions_subsets.csv`：后移上限0/5下各64组合的三方判定及直接核。
- 生产 `run_*` 目录：详细时刻表数据、见证、配置及逐轮报告。

完整集合与直接核对照均使用SAT第一层，保持业务输入和预算一致。每个模式一次运行的秒数仅为
本机小例观察，不代表稳定性能结论；可行见证和最优选择存在多解时也不要求逐项相同。

## 验收内容

保留全部原有MILP/SAT验收，并追加：

1. 手工小例隔离候选自身活动、空轨道、同候选多车、跨候选与既有车冲突、到发间隔和禁越行；
   对唯一冲突的实例检查核归属，避免条件遗漏产生错误空核或单候选核。
2. 复杂算例后移0/5各64个子集：普通SAT、assumptions SAT与MILP判定一致；每个UNSAT核都用
   原构建器重建并经普通SAT和MILP复核。可行见证仍经独立检查。
3. 三个算例分别运行完整集合与直接核流程，每轮检查客流守恒、分段座位和目标重算；复杂算例
   对每条新割检查所有64组合，确认不排除任何已知可行组合。
4. 复核零预算和真实UNKNOWN回退、原问题零预算不加割、空核独立复核背景并终止、总预算和轮数限制。
5. CSV正式入口、非法模式、MILP与核模式不兼容、非法复核预算及候选归属错误。

核复核SAT和异常出口保留防御性回退；正常编码的正确核不应触发这些路径。本验收不伪造
求解器结果来替代真实验证，也没有大规模性能或进一步核缩减实验。
